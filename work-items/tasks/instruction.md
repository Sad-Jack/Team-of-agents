# Инструкция по задачам

Используй этот шаблон для каждой новой задачи в `work-items/tasks`.

## Формат файла
- Имя файла: `YYYY-MM-DD-short-title.md`
- Один файл = одна задача

## Шаблон задачи

```md
# Task: <краткое название>

## Статус
[создан / выполнен]

## Цель
Зачем нужна задача, какую проблему решает.

## Описание
Что именно нужно реализовать.

## Контекст
Связанные задачи, ограничения, важные детали домена.

## Поведение системы
### Вход
...

### Логика
...

### Выход
...

## Сценарии
### Основной
1. ...
2. ...

### Альтернативные
- ...

### Ошибки
- ...

## Затронутые части
- Backend:
- Frontend:
- Database:
- API:
- Integrations:

## Acceptance Criteria
- [ ] ...
- [ ] ...

## Ограничения
- ...

## Вопросы
- ...

## Проверка
1. ...
2. ...

## Ответственный
<имя или роль>
```

## Когда задача считается выполненной
- Поведение реализовано по описанию.
- Acceptance Criteria закрыты.
- Основные сценарии проверены.
- Статус изменен на `выполнен`.
