# ADR-001: Использовать JSON-хранилище на MVP

- Status: accepted
- Date: 2026-05-02
- Tags: mvp, storage
- Related Tasks: TASK-1

## Context

Нужна простая локальная схема хранения без БД.

## Decision

Хранить данные в JSON-файлах до следующего этапа.

## Consequences

Просто запускать локально, но ограниченная масштабируемость.
